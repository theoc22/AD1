Dado um array circular, para cada elemento encontrar o próximo elemento maior que ele. Se não existir, retornar -1.

O array é circular, ou seja, após o último elemento volta ao primeiro.

Exemplo:

```
Entrada:  [1, 3, 2]
Saída:    [3, -1, 3]
```

- `1` → próximo maior é `3`
- `3` → não existe nenhum maior → `-1`
- `2` → próximo maior é `3` (voltando ao início)
